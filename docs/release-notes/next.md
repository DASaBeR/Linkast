## What's new

### Dedicated Recording tab
- Moved all recording options out of the Quality tab into a new **Recording** tab organized into **When I go live**, **Vertical recording**, and **Files**.
- Added a live recording summary banner that shows at a glance what will be sent and saved when you go live, plus an updated tooltip on the **Record** button.

### Editable vertical preview on the main page
- Added a live side-by-side **Vertical recording** 9:16 preview next to the main **Stream** preview whenever vertical recording is enabled, with real dimensions and a **REC** indicator per active output.
- Drag, resize, and trim cameras, overlays, and the game frame independently in the vertical preview — both before going live and live during a stream or recording.
- Added **Show vertical preview** visibility controls, a toggleable short-video **Safe zones** guide overlay, one-click vertical quick layouts (**Game top · camera bottom**, **Camera top · game bottom**, **Full game · camera corner**), empty-state cards, and responsive compact/collapse behavior in narrow windows.
