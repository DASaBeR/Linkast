# Linkast 0.5.0-beta.5

Every scene now has its own game and its own overlays, and switching between them while live is instant. This release also fixes a camera that came out seconds late and choppy, and an End stream button that stayed greyed out.

If you are coming from an earlier beta, also see the [0.5.0-beta.4 notes](0.5.0-beta.4.md): scenes, the audio mixer, Starting soon and Ending.

## New

- **Each scene has its own game, window or display.** The Capture card (Source tab) is now "Capture for" the scene that is on: switch scenes to give each one its own. While live, going from your Dota 2 scene to your Deadlock scene is instant, as long as both games were open when you went live. Scenes that use the same game share it.
  - **Change the game while live.** Pick another window or display on the Capture card and the stream switches to it after a pause of a second or two, without ending. The same happens when you switch to a scene whose game was started after you went live.
  - **A game that closes** is dropped from the stream within a few seconds; the stream carries on.
  - **Each game's sound has its own fader,** heard only while its scene is on.
- **Each scene has its own overlays,** each with its own spot, size and trim. The Overlays tab shows the overlays of the scene that is on.
  - **From another scene › Add to this scene** copies an overlay from another scene, placed and sized as it is there. The overlay itself (its alert link or picture) is shared; its place in each scene is separate.
  - The trash button takes an overlay out of this scene. It is deleted only when no other scene has it.
  - Up to 8 overlays in all scenes together (was 3).
- **Trim (crop) anything.** Cameras and overlays now have edge handles like the game picture: drag an edge to resize that side, or hold **Alt** and drag an edge or a corner to trim the picture there, as in OBS. Trims apply live.
- **Test sound for alerts.** Every alert or web overlay's fader on the Audio tab has a **Test sound** button. It plays a short chime through that overlay, so you hear it, see it on the meter and read how loud it is in the stream (with a hint when it is too loud or too quiet). While live, viewers hear it too.
- **The Audio tab follows the scene.** It shows the name of the scene that is on and only that scene's sounds, and each fader has a button to silence that sound in this scene only.

## Fixed

- **The camera was seconds late and choppy while the game looked fine.** While Linkast waited for the server at the start of a stream, the clock that every layer is timed against restarted instead of catching up, so camera and alert frames were held back by that wait. It now catches up.
- **End stream stayed greyed out** and could not be clicked.

## Changed

- Your settings are upgraded: every scene gets the game you had chosen (none for scenes that hid the game, such as Starting soon) and the overlays it showed, where they were.
- "Webcam only" on the Capture card is now **No game (cameras and overlays only)**.

## Known limitations

- **Not code-signed yet,** so Windows SmartScreen may warn: More info › Run anyway.
- **New this release and not yet tested in long real streams:** several games in one stream, switching games live, trims, and the test sound. Please report anything odd with the log from `%LOCALAPPDATA%\Linkast\logs`.
- At most 4 different games, windows or displays in one stream. Each one keeps running while its scene is off, which costs some CPU and GPU, so let scenes share a game where you can.
- The black-capture warning watches only the first captured game window.
- A camera's trim is the same in every scene (an overlay's trim is per scene).
- Each web overlay uses about 100 MB of memory for its own browser.
