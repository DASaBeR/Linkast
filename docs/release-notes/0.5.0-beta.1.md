# Linkast 0.5.0-beta.1

Better help with games in exclusive fullscreen. Linkast now tells you when a game may come out black on stream, and can switch to capturing the whole display in one click. Linkast never touches the game itself, so this is safe with anti-cheat.

## New

- **A warning only when it applies.** The old note under every window capture ("exclusive fullscreen can capture as black") is gone. When you capture a single window or game, Linkast checks it every few seconds while the Stream page is open or you are live. A yellow hint appears on the Stream page when:
  - the game is in exclusive fullscreen,
  - the stream really shows the game as black for more than 3 seconds, or
  - "Disable fullscreen optimizations" is ticked for the game, which makes a black capture more likely.

  The hint stays when you switch from the game back to Linkast, so you can still act on it.
- **Capture this display instead.** One click captures the whole display the game is on, with Desktop Duplication. Linkast asks first and warns you that **everything on that display may appear on stream, including notifications, chat and other windows**. While you capture a display, a note under the source says so too. If you are live, the stream restarts in a few seconds.
- **Fullscreen optimizations, explained.** If they are turned off for your game, the hint shows how to turn them back on (right-click the game's .exe › Properties › Compatibility). Linkast never changes another program's settings.

## Fixed

- **Desktop Duplication no longer ends the stream** when a game switches between fullscreen and windowed, the resolution changes, a Windows security prompt opens or the PC locks. Linkast restarts the capture by itself and keeps trying for about 45 seconds. Your stream shows *Reconnecting* briefly, and a recording continues in a new file.
- **Laptops with two GPUs:** when Desktop Duplication can't capture the display, the message now says why and suggests Windows Graphics Capture instead.

## Known limitations

- **Not code-signed yet,** so Windows SmartScreen may warn: More info › Run anyway.
- **Not tested with games yet.** The new checks were tested with test windows and on the development PC (NVIDIA RTX 3070). Some games in true exclusive fullscreen may stay black with every capture method; switch those to borderless windowed. Reports from the [field test plan](../field-test-plan.md) (A3) are very welcome.
- **Recording starts with the stream.** To record a stream, tick **Also record when I go live** before going live.
- **Discord shows your own camera mirrored** in its preview, including Linkast Camera. Others in the call see it the right way round.
