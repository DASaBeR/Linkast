# Linkast 0.5.0-beta.3

Arrange your stream with the mouse. Overlays and the game picture can now be dragged and resized right in the Output preview, every overlay is easy to find and select, the game picture can be trimmed like a source in OBS, the Be right back screen can play a looping video, and the OBS import brings over more.

## New

- **Drag overlays anywhere.** Click an alert box, chat box or logo in the Output preview (or in Webcam Studio) and drag it where you want it; drag a corner to resize. The position list gains "Custom" for overlays placed this way, and the nine fixed spots still work. Moves and resizes apply instantly while live.
- **Find and select overlays easily.** While the Overlays tab is open, the Output preview outlines every overlay and shows its name. Click an overlay's card to select it: the card is highlighted, and in the preview the overlay is tinted, flashes, gets its handles and a tag with its name and size. The pin button on a card scrolls to the preview and points the overlay out. Clicking an overlay in the preview selects its card too.
- **Page width and height for alerts,** like Width and Height in an OBS browser source, and a line under each overlay that says how big it is on stream and where (for example "480 × 270 at 1400, 40 on the 1920 × 1080 stream"). A dragged overlay keeps its scale when the page size changes, as in OBS.
- **New alert overlays start like in OBS:** an 800 × 600 page at its own size, centred, instead of covering the whole stream. Choosing a corner or another spot for an overlay that was full screen now also makes it smaller, so the spot takes effect.
- **Scale and trim the game picture.** Click the game picture to select it. Drag a corner to scale it (shape kept), drag an edge to resize that side, and **hold Alt while dragging an edge to trim** the captured picture on that side, the way OBS crops a source. The trim is saved with the layout and applied in the stream. Changes to the game picture apply the next time you go live.
- **A new overlay while live.** Adding a picture, or saving an alert link, while you are live asks whether to restart the stream (a few seconds) so it shows right away. Say no and it appears next time.
- **Be right back with a video.** Use my own video… on the Be right back card plays a clip on a loop while the screen is on, for a "Starting soon" or "Thanks for watching" screen: switch it on before you go live or before you end. The clip's sound is not streamed; the preview shows the card with the file name instead of the video.
- **Import from OBS brings over more:** the encoder preset, the keyframe interval, the recording format (MP4 or MKV), the streamed audio track's bitrate, and the network adapter OBS was bound to. A profile folder on its own (OBS's Profile › Export, or a copied profile folder) now imports too. Overlays keep the exact place they had in OBS. When OBS used a user name and password for the server, the import says that this is not taken over.

## Fixed

- The OBS import read audio track 1's bitrate even when OBS streamed another track, and kept recording paths with doubled backslashes.

## Known limitations

- **Not code-signed yet,** so Windows SmartScreen may warn: More info › Run anyway.
- **The looping video and the trim are new and were tested with FFmpeg's filter graph, not yet in a long real stream.** If the looped clip hitches at the end of each loop, or a trimmed picture looks wrong, please report it with the log from `%LOCALAPPDATA%\Linkast\logs`.
- **Recording starts with the stream.** To record a stream, tick **Also record when I go live** before going live.
- **Discord shows your own camera mirrored** in its preview, including Linkast Camera. Others in the call see it the right way round.
