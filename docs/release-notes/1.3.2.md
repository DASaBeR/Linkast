# Linkast 1.3.2

Quieter sounds are now easy to set, every destination remembers its own server and key, and switching games while you stream is steadier.

## New

- **Mixer faders move in decibels.** Each fader goes from silent, through -80 dB, up to +18 dB, with a firm stop at 100 %. Before, everything below 100 % had only a sliver of the fader, so a game could not be turned down gently.
- **Each destination remembers its own values.** Twitch, YouTube, Kick, Facebook and Custom each keep their own server address and stream key. Switch tabs and nothing is lost: enter your Kick key, switch to Custom, enter another server and key, and both are still there the next time you come back, and after a restart. Keys stay encrypted for your Windows user.
- **Kick: your own server address.** Kick gives every account its own server address. The Kick tab now has a Server box (filled with a default) where you can paste yours from the Kick dashboard.
- **The list of game windows updates by itself.** A game you start after Linkast appears in the list within a few seconds. You no longer need to press Refresh or restart Linkast to choose it.

## Fixed

- **Switching to another game while live.** Refreshing the window list could briefly drop the game from the stream, or pick whichever window came first. Refreshing no longer changes what the stream captures, and the Capture card keeps showing the game your scene uses.
- **The camera in the Just chatting scene could be missing.** The scene's background could be drawn over the camera, and a scene could end up with no camera at all. The background is now always at the bottom, and Just chatting always shows a camera when you have one.
- **Sound slowly falling behind the picture.** If Linkast was briefly slowed down, the sound did not make up the lost time. It now catches up.

## Tips

- **If sound and picture still seem apart,** send the log (**Copy report** or **Open logs**). The 30-second lines now say how far the sound is behind the clock ("audio N ms behind the clock") and how many frames were skipped, and the log says when a game or sound is added to or removed from the stream and when a game delivers its first picture.
- **The mixer still shows percent** next to the fader, with the decibel value beside it. 100 % is unchanged.

## Known limitations

- If you remove the camera from the Just chatting scene on purpose, it is put back the next time Linkast starts.
- The limitations of [1.3.0](1.3.0.md) still apply.
