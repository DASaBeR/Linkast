# Linkast 1.3.0

You can now send your stream through a proxy such as v2rayN, Kick works with the server address exactly as its dashboard shows it, and going live no longer times out at the start.

## New

- **Proxy for your stream.** On the **Network** tab, choose **SOCKS5** or **HTTP**, enter the address and port (for v2rayN on this PC: `127.0.0.1`, port 10808 for SOCKS5 or 10809 for HTTP) and, if your proxy needs it, a user name and password. Only the stream goes through the proxy; your game and other apps keep their normal connection. **Test connection** checks the proxy and the server together. The password is stored encrypted for your Windows user.
- **A smarter microphone noise filter.** **Remove background noise** now tells speech from room noise, fans and breaths, and adapts to your microphone and volume. The old filter used one fixed level, so at a high microphone volume it never closed and breaths came through.
- **Kick server address.** Paste the server exactly as Kick shows it (for example `rtmps://…global-contribute.live-video.net`). Linkast adds the `/app` part itself, and no longer says "The server URL needs an application path".

## Fixed

- **Going live could fail with "pipe.connect_timeout".** FFmpeg and Linkast each waited for the other when the stream started. Linkast now starts the picture first, then the sound, and reports at once if FFmpeg stops early, with details of what was waiting.
- **"Audio gain must be between 0 and 4."** The volume faders go up to 800 %, but going live refused anything above 400 %. Both now allow 800 %.
- **Sound and picture could start slightly apart.** The sound clock now starts when the stream really starts.
- **Error messages when a stream ended.** Ending or losing a stream no longer fills the log with "Pipe is broken" errors, and a sender that never got going is stopped.
- **An empty gray frame in the scene editor** and the preview, in scenes that show no game or screen.

## Tips

- **"The upload is not keeping up"** means one connection to your server can't carry the bitrate you chose, even if a speed test shows more (a speed test uses many connections at once). It is common through a proxy or a far-away server. Lower the bitrate, or let **Find the best settings** measure it.
- **Kick** accepts up to 8000 kbps, but 3000 to 6000 kbps is usually steadier when your connection or proxy is slow.
- **Microphone volume**: 800 % also boosts hiss. Around 100 to 300 % with **Remove background noise** on sounds cleaner.

## Known limitations

- The new noise filter is tuned for a single voice. If it cuts the start of a word or lets a breath through, tell us which microphone you use.
- Linkast does not read the Windows proxy settings; enter the proxy yourself. A proxy with an encrypted (TLS) connection to the proxy itself is not supported.
- The limitations of [1.0.4](1.0.4.md) and earlier still apply.
