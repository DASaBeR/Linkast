# Linkast 0.3.0-beta.2

A small fix for [0.3.0-beta.1](0.3.0-beta.1.md), the redesigned Linkast.

## Fixed

- **The Linkast logo** in the header and on the About page is the real artwork again. 0.3.0-beta.1 showed a simplified drawing of the mark there.

Everything else is the same as 0.3.0-beta.1; see its notes for the new design.

## Known limitations

- **Not code-signed yet,** so Windows SmartScreen may warn: More info › Run anyway.
- **Tested hardware so far:** only an NVIDIA RTX 3070 with a phone used as a webcam. See the [field test plan](../field-test-plan.md); reports are very welcome.
- **Exclusive-fullscreen games** may capture as black; use borderless windowed mode.
