# Linkast 0.4.0-beta.2

Camera fixes for [0.4.0-beta.1](0.4.0-beta.1.md), found while testing with a phone used as a webcam (Iriun).

## Fixed

- **A camera another app is using** (for example Discord, Teams or Zoom) now says so: "being used by another app… Linkast will pick it up automatically". Before, Linkast said the camera had "stopped working or was unplugged". Phone-camera apps such as Iriun serve one app at a time, so this happens often.
- **Remove background:** the "Camera on" icon and text no longer show through the empty area behind you in the Webcam Studio preview.
- **Background picture name:** the panel shows your picture's own name (for example "beach.jpg") instead of an internal code. This applies to pictures you choose from now on.
- **Diagnostics** now include Windows' own reason when a camera fails, which makes camera problems easier to track down.

Everything else is the same as 0.4.0-beta.1; see its notes for the streamer essentials (alerts and overlays, Be right back, recording, hotkeys, importing from OBS, Find the best settings).

## Known limitations

- **Not code-signed yet,** so Windows SmartScreen may warn: More info › Run anyway.
- **Tested hardware so far:** an NVIDIA RTX 3070 with a phone used as a webcam (Iriun). See the [field test plan](../field-test-plan.md); reports are very welcome.
- **Exclusive-fullscreen games** may capture as black; use borderless windowed mode.
- **Recording starts with the stream.** To record a stream, tick **Also record when I go live** before going live.
- **Discord shows your own camera mirrored** in its preview, including Linkast Camera. Others in the call see it the right way round.
