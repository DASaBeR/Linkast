Linkast — UI inventory

Every screen, section, tab and control in the Linkast desktop app, with a one-line note on what it does. Written as a starting point for a UI/UX refactor.

App version 0.5.0-beta.6 · Windows desktop app (WPF, Windows 11 look) · Prepared 28 October 2026 from the app's source

What Linkast is. A lightweight, local-only live-streaming app for Windows (an OBS alternative for gamers). It captures a game, window or display, adds webcams with effects and overlays (alerts, logos), mixes sound, and streams to Twitch, YouTube, Kick, Facebook or any RTMP server. You can pick which network the stream uses (for example Wi-Fi vs. a phone hotspot). No account, no cloud, no telemetry.

Key ideas behind the UI
  • Sources are set up once, scenes decide what shows. A scene says which game, cameras, overlays, background and sounds appear. Switching scenes while live is instant.
  • Live vs. not live. Some settings are locked while streaming LOCKED LIVE; others work instantly while live WORKS LIVE. The UI should make this obvious.
  • The Linkast window is often on stream itself, so secrets (stream key, alert links) are masked or hidden after entry.
  • Dark and light themes plus "Match Windows". Every colour comes from design tokens (section 3).

1. Window structure

One main window, default 1280 × 820, minimum 960 × 620, centred on screen. No secondary windows except standard Windows message boxes and file pickers.

+------------------------------------------------------------------------------+ | HEADER 56px [icon] Linkast [BRB] [MIC MUTED] [LIVE 00:12] [LOCAL ONLY] | +------+-----------------------------------------------------------------------+ | NAV | PAGE (one at a time) - Stream page shown | | RAIL | | | 72px | +------ main column (min 460px) -------+ +--- status (300px) ---+ | | | | Output preview card | | Stream status | | |Stream| | scene strip + preview canvas | | [warning / error] | | |Webcam| | [capture warning] | | Stream health | | |Setti.| | Tabs: Source Audio Scenes | | Activity (log) | | |About | | Destination Network Quality | | version / update | | | | | Overlays | | | | | | | (cards of the selected tab) | | | | | | +--------------------------------------+ +----------------------+ | +------+-----------------------------------------------------------------------+

Pages scroll vertically; nothing scrolls horizontally except the audio mixer strip. Webcam Studio and Settings are capped at 1100 px wide, About at 860 px.

2. Logo and brand assets

The mark: an "L" whose stem is shared with a "k" (arm and leg), filled with one continuous gradient cyan → blue → violet. The app icon places the mark on a deep-navy rounded square. The vector source of truth is src/Linkast.App/Themes/Brand.xaml; a script renders the .ico and PNGs from it.

16. Notes for the redesign

Things we noticed while listing the UI. They are not decisions, just places to look.

  • Stream page is dense. 7 tabs plus a status column. Some tabs (Scenes, Overlays) are scene editing; others (Destination, Network, Quality) are one-time setup. They could be split differently.
  • One control, two jobs. The segmented control is used both as tabs and as value pickers (platform, shape, background mode), so it's hard to tell navigation from settings.
  • "Scene" vs "Layout". The Webcam Studio Layout tab lists the same scenes as the Stream page strip but calls them layouts.
  • Duplicates. Mic mute (Audio tab + status card); scene reorder/duplicate/delete (context menu + Scenes tab); silent-in-this-scene (mixer button + Scenes tab checkboxes); Copy diagnostics / Open logs (Activity card + Settings).
  • Live-locked controls are only greyed out; there is no label saying why or what still works live.
  • Lots of long hint text under controls; much of it explains interactions (drag, Alt-trim) that could be shown visually or once.
  • Checkboxes used as on/off switches ("On", "Camera on", "Keep my face in frame"); a toggle switch might read better.
  • System message boxes for confirmations do not match the app's look.
  • Hard-coded colours outside the token system (preview backgrounds, placeholder text, theme thumbnails).
  • Fixed widths: status column 300 px, inspector 360 px, layout side panel 290 px; at the 960 px minimum window width the main column gets tight.
  • Privacy matters visually: the window is often captured on stream, so keys and alert links must stay hidden by default in any new design.
